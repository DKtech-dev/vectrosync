## Judge Q&A anchors

- **Is it field validated?** No. It is ready for retrospective and shadow-mode evaluation.
- **Is the rod PDE executed?** No. The current card path is reduced order; a transient solver is a validation roadmap item.
- **Is the PINN trained?** No. Random weights are not used as learned evidence.
- **Does it control Modbus?** No. There is no actuator implementation; safety authority remains external.
- **Are savings proven?** No. The repository exposes planning assumptions and sensitivity cases.
- **What is defensible today?** Working integrated software, transparent model status, fail-closed data handling, explicit constraint feasibility, and a rigorous pilot plan.
